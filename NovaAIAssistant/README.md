# NOVA AI — Siri-Style Personal Voice Assistant (Android Studio Project)

مساعد صوتي شخصي ذكي لنظام Android مبني باستخدام **Kotlin** و**Jetpack Compose**، مستوحى من أسلوب واستخدام **Apple Siri**:
- واجهة صوتية غامرة بدون فقاعات محادثة ولا حقول كتابة تشغل الشاشة الرئيسية.
- تفاعل أساسي بالصوت مع كرة صوتية نيون ثلاثية الأبعاد متحركة تتفاعل مع ترددات الصوت.
- بطاقات إجراءات تفاعلية ذكية (Siri Cards) للمنبهات، البطارية، التقويم، التطبيقات، والمكالمات.
- ميزة «الكتابة إلى المساعد» (Type to Siri) كواجهة سفلية منبثقة عند الحاجة.
- ميزة كلمة التنبيه «يا نوفا» عبر Foreground Service مع شرح قيود Doze Mode والبطارية.

## متطلبات التشغيل:
1. Android Studio Ladybug (2024.2.1) أو أحدث.
2. JDK 17 (Java 17).
3. Android SDK 35 (Android 15).
4. مفتاح Gemini API من Google AI Studio يوضع في `local.properties`.
